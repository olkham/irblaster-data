You rarely need these by hand. The hub’s web page reads this site, flags nodes running older firmware and installs the update for you.

These are update images. Install one from a node’s own page (Settings → Firmware update) or from the hub (Settings → Update hub firmware…). For a board that won’t start, or a blank one, use the recovery tool. Check a download against its SHA-256 with sha256sum (Linux), shasum -a 256 (macOS) or certutil -hashfile <file> SHA256 (Windows).

Recovery tool

Reinstalls the firmware over USB, for a board that won’t start or a blank one.

Plug the board in with a USB data cable, open the app, click Connect, then Recover. It downloads the current firmware from this site and keeps the board’s settings unless you ask it to erase them. Nothing to install: it is a single program. The app isn’t code-signed yet: on Windows choose More info → Run anyway; on macOS open it once, then choose Open Anyway in System Settings → Privacy & Security.
